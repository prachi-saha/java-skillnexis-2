# Java OOP Programs

This repository contains Java programs based on Object-Oriented Programming (OOP) concepts.

## Programs Included

1. **student.java** – Creates a Student class with name, marks, and roll number.
2. **bankacc.java** – Implements deposit() and withdraw() methods.
3. **vehicle.java** – Demonstrates inheritance using Vehicle and Car classes.
4. **shape.java** – Demonstrates interfaces using area() and perimeter() methods.
5. **method.java** – Demonstrates method overloading and method overriding.

## Concepts Covered

- Classes and Objects
- Methods
- Inheritance
- Interfaces
- Abstraction
- Polymorphism
- Method Overloading
- Method Overriding

## Language Used
Java

## Purpose
To understand and practise the fundamental concepts of Object-Oriented Programming in Java.
